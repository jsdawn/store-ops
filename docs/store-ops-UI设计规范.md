# store-ops UI 设计规范

> 版本 v1.1 · 2026-10-05（v1.0 精简修订）
> 来源：Ardot 设计稿「store-ops 会员中心 · UI设计稿」
> 适用范围：store-ops C 端小程序（uni-app，750rpx 基准，设计基准 375 × 844 pt，1 pt = 2 rpx）

## 定位说明

本规范只约束**跨页面的一致性**：统一的色彩、组件标准、导航与交互形态。**页面布局结构与具体设计不做硬性规定**，各页面按实际需求自行组织，不必套用会员中心的卡片顺序、栅格或字号组合。

风格基调：活泼明快——暖奶油底、鲜橙主色、明黄点缀、圆润卡片、线性图标。

---

## 一、导航与页面框架

### 1. 顶部导航（两种形态，按页面类型选用）

| 形态 | 适用范围 | 说明 |
| --- | --- | --- |
| 沉浸式渐变卡 | 仅限少数主页面（当前仅会员中心；后续新增需评审确认） | 渐变自状态栏起、内容沉浸头部，页面级滚动 |
| 微信原生导航栏 | 其余全部页面：列表、详情、表单、设置等内页 | `"navigationStyle": "default"`，标题居中，不自行绘制返回/标题 |

判断规则：页面属于底部 Tab 直接承载的主页面，才可考虑沉浸式；凡是导航进入的内页，一律原生导航栏，不做个性化头部。

### 2. TabBar

统一使用微信小程序**原生 TabBar**，不做自定义样式：

- 选中色 `#FF7A29`，未选中色 `#8A8698`（`app.json` 的 `selectedColor` / `color` 配置）
- 图标、字号、间距、高度均由系统渲染，不覆盖
- 设计稿中 TabBar 一律按原生默认外观绘制（白底、直角、无投影），不画圆角悬浮样式

## 二、色彩体系

跨页面必须统一的部分。新增页面不得引入新的主色/功能色，可在点缀色范围内取用。

### 2.1 品牌与功能色

| 角色 | 色值 | 使用场景 |
| --- | --- | --- |
| 主色 | `#FF7A29` | 选中态、强调按钮、徽章、链接类文字 |
| 主色渐变 | `#FF9A3D → #FF6B5C`，45° | 仅沉浸式主页面头部、主按钮背景 |
| 辅色 | `#FFC93D` 明黄 | 进度条、活动徽章渐变（`#FFE08A → #FFC24D`，0°） |
| 页面背景 | `#FFF6EC` | 全局页面底色 |
| 卡片/弹层背景 | `#FFFFFF` | 内容卡片、弹层面板 |

### 2.2 点缀色（图标/分类入口，色与底板成对使用）

| 名称 | 图标色 | 底板色 | 典型场景 |
| --- | --- | --- | --- |
| 蓝 | `#4D9FFF` | `#E8F1FF` | 记录/账单、信息类 |
| 绿 | `#34C77B` | `#E6F9EE` | 商城、正向操作 |
| 粉 | `#FF5C7A` | `#FFE9F0` | 券、客服类 |
| 暖黄 | `#F5A623` | `#FFF6DC` | 优惠券、充值类 |
| 橙浅底 | `#FF7A29` / `#FF9A3D` | `#FFF0E4` / `#FFF6EC` | 品牌强相关入口 |

语义色直接复用点缀色，不引入新色相：成功 `#34C77B`、警示 `#F5A623`、错误 `#FF5C7A`。

### 2.3 文字与中性色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主文字 | `#2D2A32` | 标题、数值 |
| 次要文字 | `#8A8698` | 描述、说明 |
| 弱提示文字 | `#B5B2C2` | 辅助信息 |
| 箭头/未选描边 | `#C9C6D4` | 列表箭头、未选态 |
| 分隔线 | `#F4F2F8` | 卡内行分隔、竖分隔 |
| 遮罩 | `#2D2A32` @ 45% | 弹窗遮罩 |

渐变卡深底上：主文字纯白、次文字白 @ 72%。

### 2.4 字体

中文 Noto Sans SC（落地 PingFang SC / 系统默认）；数字 Inter Tight（落地 `font-variant-numeric: tabular-nums`）。字号、行高、字重由各页面按内容层级自行把握，仅要求：同页面内层级分明（标题 > 正文 > 辅助），数字用等宽字体。

## 三、组件规范

交互组件（按钮、表单、弹出层、Toast 等）**遵循微信官方 WeUI / 小程序社区规范**的尺寸、结构与默认交互，在此之上只做品牌色替换。不自行发明组件形态。

### 3.1 按钮（WeUI button 为基准）

| 变体 | 品牌化参数 | 使用场景 |
| --- | --- | --- |
| 主按钮 | `#FF9A3D → #FF6B5C` 45° 渐变（或纯 `#FF7A29`），白字 | 弹层确认、关键操作 |
| 次按钮 | 底 `#FFF6EC`、描边 `#FFCFA8`、文字 `#FF7A29` | 扫码等次要入口 |
| 浅底强调 | 底 `#FFF0E4`、文字 `#FF7A29` | 「查看明细 ›」类小入口 |

尺寸、圆角、按压/禁用/loading 态均按 WeUI 默认。渐变仅用于主按钮，普通按钮不滥用渐变。

### 3.2 选择器：底部弹出（Bottom Sheet）

需要选择（门店、分类、筛选等）时统一用底部弹层，不用居中弹窗：

- 遮罩 `#2D2A32` @ 45%，点击关闭；面板白底、顶部圆角 20、含拖拽指示条
- 选中项：描边 `#FF7A29` 1.5pt + 橙底白勾单选标记；未选中：描边 `#C9C6D4`
- 入场/出场按社区惯例（约 240ms/200ms ease-out），支持下拉关闭

### 3.3 列表与其他组件

- 列表行：图标底板（点缀色成对）+ 标题/副文案 + `#C9C6D4` 右箭头，按压变 `#FFF6EC`
- 表单输入：聚焦描边 `#FF7A29`、错误描边 `#FF5C7A`，其余按 WeUI
- 徽章：`#FF7A29` 底白字（状态）；`#FFE08A → #FFC24D` 渐变底 + `#7A4A00` 字（活动/等级）
- Toast、对话框、下拉刷新：用系统/WeUI 默认，刷新圈色用 `#FF7A29`

---

## 四、图标风格

- 单色线性 outline，圆头端点，线宽 1.7–1.8pt，24×24 网格；底板与图标取同一点缀色对
- 同一页面内图标风格、线宽一致；不混用填充图标与多色图标

---

## 五、不做硬性规定的部分

以下内容供参考，不构成约束，各页面按需设计：

- 页面布局结构、卡片数量与顺序、栅格与具体间距
- 字号层级组合、圆角/阴影的逐项参数（保持同页面内部一致即可）
- 沉浸式页面（如会员中心）的头部细节，作为参考范本而非模板

---

## 六、落地速查

- 单位：设计稿 pt × 2 = rpx
- CSS 变量建议：`--color-primary: #FF7A29`、`--color-bg: #FFF6EC`、`--color-text-main: #2D2A32` 等，色值与本文档一一对应
- TabBar 配置：`"color": "#8A8698", "selectedColor": "#FF7A29"`
- 设计稿源文件：Ardot「store-ops 会员中心 · UI设计稿」（TabBar 已按原生直角外观修订）；新增页面建议先扩展画板，色彩与组件按本文档对齐
